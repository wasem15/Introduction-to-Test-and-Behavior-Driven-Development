# TDD / BDD Practice Project

A Python testing project focused on Test-Driven Development (TDD) and Behavior-Driven Development (BDD).

## What it demonstrates

- Automated unit testing
- Behavior-driven feature specifications
- Separation between service logic and test scenarios
- Feature-first test organization

## Repository structure

~~~text
tdd-bdd-final-project/
├── features/       # BDD feature specifications
├── service/        # Application/service implementation
└── tests/          # Automated tests
~~~

## Engineering focus

The repository emphasizes designing behavior through tests and keeping application logic independently testable.

## Portfolio context

This is a supporting software-engineering project demonstrating testing discipline rather than a standalone product.
